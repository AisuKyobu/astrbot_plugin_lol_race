# lolrace

LOL内战系统 — AstrBot 插件

## 功能

- 报名注册（电1游戏ID + 段位 + 位置）
- 每日签到/取消签到
- 查询选手信息（关键词或 @群友）
- 我的战绩（个人数据统计）
- 修改个人信息
- 登记战绩（@MVP）
- 同步群昵称
- 管理员切换签到开关
- 后端自动分队（钻石/钻石以下分层，5位置平衡）
- 每日凌晨自动清空签到和分队数据

## 指令列表

| 指令 | 说明 |
|------|------|
| `报名 <电1游戏ID> <段位> <主选> [次选] [备注]` | 注册选手 |
| `签到` | 今日参赛打卡 |
| `取消签到` | 取消参赛 |
| `我的战绩` | 查看个人数据 |
| `查询 <关键词> 或 @群友` | 查询选手信息 |
| `修改信息 <段位> <主选> <次选>` | 更新个人资料 |
| `登记战绩 <蓝方\|红方> @MVP` | 登记比赛结果 |
| `同步名称` | 更新群昵称 |
| `切换签到` | 管理员：开启/截止签到 |

## 依赖

- AstrBot >= 4.12
- httpx
- FastAPI 后端（见同级 lolRaceProject）

## 配置

安装插件后，在 AstrBot WebUI「插件管理 → LOL内战系统 → 配置」中填写：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `api_base` | 后端 API 地址 | `http://<服务器IP>:8000/api/v1` |
| `frontend_url` | 网页端地址（注册/认证链接会发给用户） | `http://<服务器IP>:5173` |

说明：

- 若 AstrBot 与后端部署在同一个 docker compose 网络内，`api_base` 可直接填 `http://backend:8000/api/v1`（容器名互访）。
- 配置持久化在 AstrBot 的 `data/config/lolrace_config.json`，更新/重装插件不会丢失。
- 不填时默认为本机地址 `127.0.0.1`。
