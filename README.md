# lolrace

LOL内战系统 — AstrBot 插件（QQ 群「小战」）

## 功能

- 群里每条消息上报后端（用于快报素材、网页登录口令、小战上下文）
- **小战人设陪聊**：被 @ 必回 + 小概率随机接话；人设、触发频率、每日上限都在网页后台「小战人设」页调
- 每日签到/取消签到（支持多场次）
- 查询选手信息（关键词或 @群友）
- 我的战绩（个人数据统计）
- 同步群昵称
- 管理员切换签到开关
- 赛事报名/取消/赛程查询
- 后端自动分队（钻石/钻石以下分层，5 位置平衡）
- 每 4:05 自动生成昨日快报、清理签到与分组
- WS 推送：开局提醒、快报、拍卖播报

## 指令列表

| 指令 | 说明 |
|------|------|
| `帮助` | 查看帮助图 |
| `注册` | 生成网页注册链接 |
| `登录` | 查看网页登录方式（群口令） |
| `签到 [场次]` | 今日参赛打卡 |
| `取消签到 [场次]` | 取消参赛 |
| `我的战绩` | 查看个人数据 |
| `查询 <关键词> 或 @群友` | 查询选手信息 |
| `同步名称` | 更新群昵称 |
| `切换签到 [场次]` | 管理员：开启/截止签到 |
| `比赛报名 [赛事名]` / `取消报名` / `赛程` | 赛事相关 |

> 修改信息、登记战绩已迁移到网页端（首页双击选手卡片 / 登录后上传战绩）。

## 小战怎么接话

```
群消息 ──▶ 插件上报 /bot/messages（带 at_bot）
              │
              ├─ 普通消息：只缓存，不回复
              └─ 被 @ / 命中随机概率：后端生成回复
                        └─ 插件把 persona.reply 发回群里
```

- 判定逻辑、上下文、预算和后端 `DEEPSEEK_API_KEY` 都在网页端配置，插件不需要额外配置项。
- 后端会跳过 `/签到` 这类指令，避免和指令处理重复回复。
- 如果 AstrBot 里还开了全局 LLM 对话，建议关掉或只给小战用，否则可能出现两条回复（插件在小战开口时会尝试抑制本条的默认 LLM）。

## 依赖

- AstrBot >= 4.12
- httpx、websockets
- FastAPI 后端（见同级 lolRaceProject）

## 配置

安装插件后，在 AstrBot WebUI「插件管理 → LOL内战系统 → 配置」中填写：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `api_base` | 后端 API 地址 | `http://<服务器IP>:8000/api/v1` |
| `frontend_url` | 网页端地址（注册/认证链接会发给用户） | `http://<服务器IP>:5173` |

说明：

- 若 AstrBot 与后端部署在同一个 docker compose 网络内，`api_base` 可直接填 `http://backend:8000/api/v1`（容器名互访）。
- 配置持久化在 AstrBot 的 `data/config/lolrace_config.json`，更新/重装插件不会丢失。
- 不填时默认为本机地址 `127.0.0.1`。
